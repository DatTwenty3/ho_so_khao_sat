# Hồ sơ khảo sát

Công cụ web tạo **nhật ký khảo sát** và **biên bản nghiệm thu** (.docx) từ lịch công việc,
giữ nguyên định dạng của file Word mẫu. Mọi xử lý chạy trong trình duyệt, không gửi dữ liệu đi đâu.

Mẫu và lịch trong repo này là **dữ liệu giả**. Nhập thông tin thật ở tab "Thông tin chung",
hoặc dùng mẫu Word của bạn ở tab "Xuất file & mẫu".

## Phát triển

```
python build.py
```

Mã nguồn ở `src/`, mẫu ở `mau/`. `index.html` là file được sinh ra, không sửa trực tiếp.
